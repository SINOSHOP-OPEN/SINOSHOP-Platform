# PID_Neural_System — 历史归档 · 接口骨架

> 本目录为早期版本的姿态控制模块归档，**仅保留公开接口与示例代码，不含生产实现**。
> `preprocessing` / `simulation` / `control_law` 三个子目录下的算法实现、
> 工程参数与标定结果均不在公开范围，此处只留接口占位。

## 目录说明

| 目录 | 内容 |
|:--|:--|
| `preprocessing/` | 传感器数据预处理的接口占位 |
| `simulation/` | 控制器模板与演示脚本（基线示例，归一化单位） |
| `control_law/` | 控制策略相关文档占位 |

## 关于示例代码

`simulation/controller.py` 是公开挑战赛的控制器模板，`compute()` 只定义输入输出接口，
具体实现由挑战者自行完成；其中出现的增益为示意取值，不构成工程标定参数。
`simulation/run_demo.py` 提供最小可运行示例，用于验证接口连通。
