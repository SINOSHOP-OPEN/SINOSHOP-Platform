## 物理架构六原则

1. **基本单元**：21m直通管 × 6管并列 → 138m宽 × 27m高扁椭圆隧道外壳，浮箱道路模块套于中心线下-3.9m，悬浮于淡化海水内舱。
2. **双隧道梯形结构**：两个138m×27m隧道 + 6m水道，25m间隔横向连通6管，150m间隔连通12管，形成整体长梯形结构。
3. **300m悬浮防波堤承托平台**：位于隧道下方，柔性连接，浮力重力比 = 1:1.03。
4. **统一标准截面**：水下段与海面段使用相同截面，潮汐发电水舱实现定深悬浮。
5. **1188m海面浮桥**：中央交通区 + 两侧生活区（各138m×27m）+ 最外侧防波堤消浪发电模块（各300m），以6m/9m水道间隔。
6. **海啸防御**：生活区/防波堤模块可独立航行靠岸或独立下沉，交通区保持定深。
